# Demo v3 motion and object art

All images were generated with built-in `image_gen`, without a paid CLI/API fallback. Sources are archived in `art/source`; packed sprites and manifests are in `public/assets`. The player references the accepted grittier diver, enemies reference `art/source/creatures.png`, and parallax layers reference the original wreck. The shark sheet received an additional transparent-background cleanup pass.

The motion assembly script uses connected components, one shared scale per form and enemy, and common anchors. No generated image is loaded from a user-specific path at runtime.
